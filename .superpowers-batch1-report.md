Consider upstream `analysis_options` exclude for Cubits or refactor to `StreamSubscription` owned by `Repository` instead of Cubit, tracked for Batch 2.
- **Remaining `EdgeInsets.all` elsewhere:** ~20 symmetric paddings (e.g., `catalog_empty_state.dart:14`, `feedback_view.dart:40`, `admin_*`) intentionally left as `EdgeInsets.all` since they are center/card paddings not directional. If audit demands 100% directional, Batch 2 should systematically convert `EdgeInsets.symmetric(horizontal:...)` → `EdgeInsetsDirectional` where start/end matters.
- **Color derivation TODO:** `_colorName` still hardcoded map; requires DB migration adding `products.color_name` or `product_colors` table plus `Product.colorName` field. Deferred to Batch 3 (data layer).
- **Timer gating future:** Current gating only short-circuits at `saleSeconds == 0`. Ideal is to suspend `_timer` entirely when `flashEnd == null` and resume via `startFlashSale`; would need feature flag or `flashEnd` watcher — low priority but noted.
- **Dependency drift:** 29 packages have newer majors (e.g., `sentry_flutter 9.25 → 9.27`, `supabase_flutter 2.16 → 2.17`) not upgraded per `pubspec.yaml` freeze constraint. Recommend Batch 2 `flutter pub outdated` review.
