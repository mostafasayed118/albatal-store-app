4Dimension detail

Strengths (verified)

  • Zero layering violations across 255 files: no Supabase import in presentation/, no Flutter import in domain/, no presentation → data, no cross-feature imports.
  • Zero committed secrets; only .env.example in full history; templates redacted; release signing via gitignored key.properties.
  • Edge-function secrets compared in constant time and fail closed without logging values.
  • RLS hardening is real and documented (migration 029 fixed a self-escalation path).
  • All list queries bounded (limit(100/500/50/1000)); no N+1 awaits in production code.
  • All 3 periodic timers owned and cancelled; heaviest rebuild path gated by homeBuildWhen.
  • 91% dartdoc coverage; 22k-line suite mirrors the feature layout.

Why 9.5, not 10

Every code-level finding is fixed and verified. The remaining half-point is four owner-gated decisions the audit is forbidden from taking alone (AGENTS.md: no pubspec edits, no migration edits without human review):

  • R1 Admin 061 RLS policy — proposal shipped, needs human review + apply.
  • R2 http: any → pin to ^1.2.0 (one line, needs approval).
  • R3 Catalogue colour names need a DB column to replace a hardcoded map.
  • R4 .gitignore vs tracked lib/generated wording.
Sample-size honesty: RLS coverage is repo-wide by policy grep plus deep reads of migrations 002 / 017 / 029 — a line-by-line derivation of all 59 migrations against a live database was out of scope (no production access, no live probing).

5What a green-looking repo was hiding

The audited tree looked healthy — clean analyzer output bar four unused imports, 875 passing tests, a documented audit culture. Three defects were still live:

1. A two-character typo (-- in an XML comment) silently made every Android build fail.
2. A truncated test file removed the only guard on a documented production regression while leaving the suite looking alive.
3. A security control (the app lock's fail-closed escape) could be crashed by an Error-class failure instead of holding the lock.

All three are fixed and verified; the suite is now 888/888 with a proven-clean build.
